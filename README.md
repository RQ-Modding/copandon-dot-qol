# Copandon Dot QoL

**Fortune** (skill 448) can now crit and stun. In the base game it can do neither. Needs loader **0.22.0**.

- **Stun:** normal stun rules (her stun rate against the target's resistance).
- **Crit:** her crit rate cut in half, plus the stealth bonus, the same rules the game uses for attacks on all enemies. A crit adds the game's usual +30 to the damage multiplier.

Bad Luck deals no damage and does not stun.

Local-only git. No remote.
