# Copandon Dot QoL

Copandon Dot's **Fortune** can land a critical hit and stun. In the game it can do neither.

## What it changes

- **Stun:** Fortune stuns by the normal rules, her stun rate against the target's resistance.
- **Critical:** her critical rate cut in half, plus the stealth bonus while she is hidden: the rules
  the game uses for attacks on all enemies. A critical adds the game's usual +30 to the damage
  multiplier.
- **Bad Luck** still deals no damage and does not stun.

## Keys and settings

None.

## Saves

Nothing.

## Works with

Better Explained: its Fortune hover says Can't Crit / Can't Stun, the game's rules. This mod loads
after it (priority 1) and changes that line to Can Crit / Can Stun.

## Install

Needs [RQ MOD](https://github.com/RQ-Modding/RQ-Mod) with loader **1.15.0** or newer. Extract the
release zip into the game's `mods` folder, so that you have `mods/copandon-dot-qol/mod.json`.
